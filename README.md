## ⚙️ Instrucciones para clonar y ejecutar el proyecto

1.  Clonar este repositorio en el equipo local o descargarlo como archivo ZIP.
2.  Abrir el proyecto utilizando el entorno de desarrollo **IntelliJ IDEA**.
3.  Navegar hasta la ruta: `src > cl.duoc.llanquihuetour > app > Main.java`.
4.  Hacer clic derecho sobre el archivo `Main.java` y seleccionar la opción **"Run 'Main.main()'"** o utilizar el botón de reproducción (Play) ubicado junto a la declaración de la clase.
5.  Los resultados de las instancias creadas se mostrarán directamente en la consola integrada del IDE.
